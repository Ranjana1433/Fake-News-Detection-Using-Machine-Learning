    ⚙️ How it works

    Text is converted to TF-IDF features (words and word pairs). A Logistic Regression model and a Naive Bayes model each estimate the chance the text is fake; the final score blends both. Rule-based red flags (shouting, clickbait, missing sources) adjust the credibility score. Note: the built-in model is trained on a small sample dataset, so use it for learning and demos; train on a large real dataset for serious use, and always verify news from trusted sources.
